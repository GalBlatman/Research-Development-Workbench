# ADR 0004: minimal loopback fake-model application

Accepted for the owner's RDW-004 scope. Reuse React/TypeScript and FastAPI/Pydantic, canonical PostgreSQL and existing private-original service. A SQLite local demo is explicit, using the same repository contract, not a replacement architecture. No deployment or authentication is claimed. Browser/API are bound to loopback; trusted-host and origin checks reject other browser origins, with no cross-origin wildcard. Do not expose this development slice on a network.

The model adapter receives a typed ContextPacket and frozen snapshot, with no database, file, HTTP or provider dependency. FixtureVerifier checks exact fake fixture conformance separately from schema validation. It does not verify scientific entailment. Supported ratings mean synthetic fixture conformance only and carry that limitation in the report; project objects remain not inspected. Limited fixtures produce pending judgments for arbitrary input; numeric fixture eligibility requires the exact synthetic texts and declared route/stage. No keywords or user acceptance establish scientific quality. A future provider must replace both inference and substantive verification under RDW-005's separate authority.

Fake tasks are synchronous, bounded, network-free and inexpensive; no durable queue is needed for this slice. Real long-running/provider tasks require the planned workflow/worker boundary. Sources and revisions remain RDW-003 records. ReviewSummary is an optional additive field in the existing immutable StoredSnapshot payload; old payloads remain valid, and no destructive database migration is required. All report/policy views are server Pydantic contracts; OpenAPI and TypeScript are generated and checked for drift. The browser displays results, statuses and exact rational traces without rubric arithmetic.

Dependencies: FastAPI 0.142.2, Uvicorn 0.54.0, test HTTPX 0.28.1, React 19.3.0, Vite 8.3.2, Playwright 1.63.0, pnpm 11.19.0. TypeScript 5.9.3 matches openapi-typescript 7.13.0's supported 5.x compiler API; TypeScript 7 does not. Prettier 3.9.9 checks frontend formatting. Exact direct pins, backend/uv.lock and frontend/pnpm-lock.yaml govern reproducibility. No framework substitution, UI kit, model SDK or telemetry. Test browsers/dependency downloads are setup operations, not model/evaluation network calls.

Minimal fake-review limitations and fixed interpretations are visible. A snapshot is never rewritten by a project/source edit; revision mismatch marks its view historical. Ordinary Markdown/JSON exports omit original source files/text and private storage references. The app export is rdw-app-1 and is not advertised as a lossless import bundle; the underlying RDW-003 portable contract remains separately available. No private-pilot readiness or independent audit is claimed. GATE-1 and RDW-005 remain unstarted.
